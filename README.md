## Overview

Cheat for Rust is an unofficial fan-made interface concept inspired by Rust's harsh survival environment, abandoned industrial locations, and post-apocalyptic atmosphere.

The project focuses on interface design, visual customization, and menu organization. It does not provide functional cheats or gameplay modifications.
